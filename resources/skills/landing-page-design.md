# Landing Page Design

## When to use

Building a marketing or project landing page.

## Checklist

- State what it is and who it is for above the fold, in plain words.
- Lead with the outcome, not the feature list.
- Give exactly one primary call to action and repeat it once further down.
- Show the product — a real screenshot beats an abstract illustration.
- Keep total weight small; inline critical CSS and defer the rest.

## Verification

- Read the first screen aloud; a stranger should understand the product.
- Measure load on a throttled connection.
