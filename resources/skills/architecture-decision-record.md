# Architecture Decision Record

## When to use

Making a decision that is expensive to reverse.

## Checklist

- State the context and the forces in tension before the decision.
- Record the options considered and why each was rejected.
- State the decision in one unambiguous sentence.
- Record the consequences, including the ones you dislike.
- Never edit a superseded record; write a new one that supersedes it.

## Verification

- A newcomer can read the record and explain the reasoning without help.
