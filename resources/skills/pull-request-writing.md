# Pull Request Writing

## When to use

Opening a pull request.

## Checklist

- Open with the problem and the chosen approach in a few sentences.
- Say how it was verified, with the actual commands and results.
- Call out anything you want scrutinised, and any deliberate trade-off.
- Keep the diff focused; move unrelated cleanups to their own PR.
- Include a screenshot or recording for user-visible change.

## Verification

- A reviewer with no context can start reviewing without asking a question.
