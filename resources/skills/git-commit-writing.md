# Git Commit Writing

## When to use

Committing work.

## Checklist

- Use the imperative mood in the subject: 'add', not 'added'.
- Keep the subject under ~72 characters and specific.
- Explain in the body why the change was needed, not what the diff shows.
- One logical change per commit; split unrelated work.
- Reference the issue and note any breaking change explicitly.

## Verification

- Read the subject alone and confirm it identifies the change.
