# Acceptance Criteria

## When to use

Turning a request into verifiable criteria.

## Checklist

- Write each criterion as an observable outcome, not an implementation step.
- Make each one independently checkable by someone who did not build it.
- Include the negative cases and the boundaries.
- State what is explicitly out of scope.
- Name how each criterion will be verified.

## Verification

- Every criterion can be answered yes or no by observation alone.
