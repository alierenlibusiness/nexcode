# Seo Structured Data

## When to use

Adding structured data markup.

## Checklist

- Use JSON-LD; it is easier to maintain than inline microdata.
- Choose the most specific schema.org type that actually fits.
- Mark up only content visible on the page — mismatched markup is penalised.
- Fill the required properties before the optional ones.
- Validate against the rich-results test before shipping.

## Verification

- Run the structured data validator and confirm zero errors.
