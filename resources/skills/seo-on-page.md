# Seo On Page

## When to use

Publishing or reviewing a public page.

## Checklist

- Give each page a unique, descriptive title under ~60 characters.
- Write a meta description that earns the click; it is copy, not keywords.
- Use exactly one h1 and a heading structure that mirrors the content.
- Write descriptive link text; 'click here' carries no signal.
- Add alt text that describes the image's purpose.
- Set a canonical URL when the same content is reachable more than once.

## Verification

- View source and confirm the title, description and canonical are present.
- Confirm heading levels are not skipped.
