# Incident Runbook

## When to use

Documenting the response to a known failure mode.

## Checklist

- Open with how to confirm the incident is happening.
- Give the immediate mitigation before the root-cause investigation.
- Use numbered, copy-pasteable commands with expected output.
- State the escalation path and who owns the decision to roll back.
- Include how to verify recovery and how to communicate it.

## Verification

- Have someone unfamiliar with the system follow it in a drill.
