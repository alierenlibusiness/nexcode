# Seo Technical Audit

## When to use

Auditing a site's technical health.

## Checklist

- Confirm important pages are crawlable and not blocked by robots or noindex.
- Check the sitemap is current and matches the canonical set.
- Fix redirect chains and broken internal links.
- Measure Core Web Vitals on real page weight, not a local build.
- Confirm mobile rendering matches desktop content.

## Verification

- Fetch and render the page as a crawler would.
- Report the measured Core Web Vitals.
