# Changelog Writing

## When to use

Preparing release notes.

## Checklist

- Group by Added / Changed / Fixed / Removed / Security.
- Write from the user's perspective, not the commit's.
- Call out breaking changes first with the required migration step.
- Link each entry to its issue or PR.
- Keep an Unreleased section so entries are written while the context is fresh.

## Verification

- Confirm every user-visible change in the diff appears in the changelog.
